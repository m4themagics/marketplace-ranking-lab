# Studies

Учебные задания к экспериментам: один каталог — одно задание на один вечер.

```text
studies/<nn>_<slug>/
  task.md      зачем, что решено заранее, порядок работы, определение готовности,
               рабочая запись из LEARNING.md
```

Задание существует, чтобы центральный TODO закрывался автором, а не агентом
([LEARNING.md](../LEARNING.md)). Текущая очередь:

1. [Permutation null band](00_permutation_null_band/task.md);
2. [Temporal split](01_temporal_split/task.md);
3. [Ranking metrics](02_ranking_metrics/task.md).

Нумерация не совпадает с `experiments/`: задание может обслуживать эксперимент, а может
закрывать пробел в треке.
