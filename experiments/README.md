# Experiments

Один каталог — один исследовательский вопрос, а не одна модель. Модель без вопроса живёт в
`src/mrl/`, а сюда попадает только то, что что-то проверяет.

```text
experiments/<nn>_<slug>/
  README.md          вопрос, гипотеза, механизм, критерий успеха
  protocol.md        заполненный research protocol — до прогона
  run.py             или Makefile-цель; ровно одна команда запуска
  results/           числа, графики, run manifest
```

Запланированные вопросы, в порядке работы:

| # | Вопрос |
|---|---|
| 00 | Обновляется ли каталог настолько, чтобы фиксированный кодбук вообще напрягся? |
| 01 | [Как меняется captured logged basket value вместе с релевантностью?](01_revenue_tradeoff/) |
| 02 | [Что даёт Two-Tower сверх ALS retrieval при одном candidate budget?](02_neural_retrieval/) |
| 03 | [Сколько recall стоит переход от exact top-k к HNSW?](03_ann_tradeoff/) |
| 04 | [Где в системе смещение и почему офлайн разойдётся с онлайном?](04_offline_online_bias/) |
| 05 | Насколько семантические ID сохраняют структуру каталога: коллизии, покрытие? |
| 06 | За сколько дрейфа каталога протухают фиксированные кодбуки и когда перестроение окупается? |

Порядок — по возрастанию предпосылок, обоснование в
[плане разработки](../docs/development-plan.md). Эксперимент 04 не содержит кода намеренно:
офлайн-репозиторий не воспроизводит A/B-контур, а имитация его не заменяет.

Нумерация закрепляется в момент старта эксперимента, а не заранее: список выше — это
намерение, и он может измениться, если предыдущий результат окажется другим.
